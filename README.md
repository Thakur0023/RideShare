# RideShare Backend

A backend application for a ride-sharing platform, developed using Java and Spring Boot.

## Technologies Used

- Java
- Spring Boot
- Maven
- Spring Data JPA
- MySQL (if configured)

## Features

- RESTful API development
- User management
- Ride management
- Backend business logic

## Project Structure

```text
rideshare-backend/
├── src/
│   ├── main/
│   │   ├── java/
│   │   └── resources/
│   └── test/
├── .gitignore
├── pom.xml
└── README.md
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Thakur0023/RideShare.git
```

### 2. Navigate to the project

```bash
cd RideShare
```

### 3. Run the application

Using Maven Wrapper on Windows:

```bash
mvnw.cmd spring-boot:run
```
